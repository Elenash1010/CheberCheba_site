# Новогодний городок «В гостях у Чебы»

Статический сайт: сборка и установка зависимостей не нужны.

Репозиторий: https://github.com/Elenash1010/CheberCheba_site

Адрес GitHub Pages: https://elenash1010.github.io/CheberCheba_site/

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После отправки изменений в `main` сайт обновляется автоматически.

## Структура

- `index.html` — разметка и тексты, включая всплывающие программы.
- `styles.css` — оформление и адаптивные стили. Порядок правил сохранён при выносе из HTML.
- `script.js` — мобильное меню и диалоговые окна.
- `assets/` — только используемые изображения и логотипы.
- `scripts/check-site.mjs` — проверка локальных файлов, якорей, изображений и загрузки по HTTP; требуется Node.js 18 или новее.

## Публикация

Загрузите в корень статического хостинга `index.html`, `styles.css`, `script.js` и всю папку `assets`, сохранив имена файлов и регистр. HTTPS включается средствами хостинга. `README.md` и `scripts/` публиковать не нужно.

Ссылки на билеты ведут на https://ticketcode.ru/organizer/cheber.
Шрифт Raleway загружается из Google Fonts; при недоступности используется Arial.

Перед публикацией добавьте документы:

- `assets/documents/privacy-policy.pdf`
- `assets/documents/user-agreement.pdf`

Ссылки на них уже находятся в подвале и открываются в новой вкладке. До добавления файлов эти две ссылки будут возвращать 404.

## Проверка

```sh
node --check script.js
node scripts/check-site.mjs
node scripts/check-site.mjs --strict
```

Обычный режим отдельно сообщает об ожидающих PDF. Строгий режим считает их отсутствие ошибкой для публикации.

После загрузки откройте сайт на компьютере и телефоне: проверьте меню, три диалога программ, ссылки на билеты, телефоны, ВК и документы.

## Изображения

Фотографии карточек оптимизированы до JPEG 768 × 1152 с качеством 90. Главное фото сохранено в размере 1540 × 1021; прозрачная надпись — PNG 760 × 504. Вес всех используемых изображений — около 4,6 МБ. Неиспользуемые исходники и дубли удалены по запросу.
